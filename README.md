An interactive Jupyter notebook for building intuition on the core topics of an undergraduate vibrations course (TU Delft AE2135-II).
Contents: 
1. **Free vibration.** How the damping ratio decides whether a mass-spring-damper is underdamped, critically damped or overdamped.
2. **Forced vibration and resonance.** The time response to a harmonic force, next to the magnification curve with the current operating point marked.
3. **Two degree of freedom system.** Natural frequencies and mode shapes from the eigenvalue problem (K − ω²M)φ = 0.

Each section states the governing equation and gives a suggestion of what to try with the sliders.
